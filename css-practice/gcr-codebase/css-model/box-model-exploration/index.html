Nested visualization showing how Margin, Border, Padding, and Content wrap around each element.

CONTENT

Inner Element Core

Margin: Clears an area outside the border. It is completely transparent.
Border: A line surrounding the padding and content. Accepts colors & styles.
Padding: Clears an area around the content. Inherits element background.
Content: The actual text, images, or child elements of the box.
