Box-Sizing Comparison

Visualizing how box-sizing: content-box vs box-sizing: border-box calculates rendered width.

Default Sizing

content-box

Content Area
Declared Width: 260px
Padding (each side): 25px
Border (each side): 10px
Rendered Total Width: 330px

In content-box, padding and border are added on top of the specified width, making the element physically wider than 260px.

Modern Standard

border-box

Content Area
Declared Width: 260px
Padding (each side): 25px
Border (each side): 10px
Rendered Total Width: 260px

In border-box, padding and border are absorbed inside the declared width. Total rendered width remains exactly 260px.
